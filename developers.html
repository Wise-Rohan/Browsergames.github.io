Browser Games gives student developers a place to share their games, experiment with new ideas, and build something other people can enjoy.

Start Developing

Create Games

Build games using Scratch, HTML, JavaScript, Python, or other technologies. Your project doesn't have to be perfect — creativity comes first.

Publish Your Work

Submit your project to Browser Games and, after review, your game can be featured on the platform for other students to discover.

🌎

Reach Players

Give your games a home where people can discover new projects and see what student developers are creating.

How It Works

1

Create an account

Sign in using your Google Account to create your Browser Games developer profile.

2

Create your game

Use the + Create Game button inside your developer dashboard to start a new submission.

3

Add your game information

Provide the title, description, category, controls, version, screenshots, and game URL.

4

Submit for review

Your game is sent for review. Once approved, it can appear in the Browser Games collection.

What You Need

  • A Browser Games developer account
  • A game you created
  • Game title and description
  • Developer name
  • Game category
  • Controls/instructions
  • Version number
  • Game URL or hosted game files
  • A game thumbnail or screenshot
